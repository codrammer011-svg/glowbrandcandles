# Glow Brand Candles

Custom WordPress application source for Glow Brand Candles.

Includes the Glow Scented Candles theme, fundraiser/dashboard modules, custom order and shipping plugins, and Glow MU plugins. The initial source snapshot incorporates the live application synchronization performed on October 13, 2026.

## Installation

Use an existing WordPress installation with the site's required third-party plugins, including WooCommerce, User Registration, Elementor and PDF Invoices & Packing Slips. Install the tracked theme and plugins into their matching `wp-content` paths, and configure WordPress credentials and services separately.

Database contents, uploads, WordPress core, third-party plugin packages, local configuration, logs, test artifacts and backups are excluded. This repository is application source rather than a complete site backup. Existing site settings and database records are required for operation.

## Changes and deployment

Compare with the current live source before deployment to preserve concurrent developer changes. Review changes and back up the target files and any affected database settings before deploying. Keep credentials and production data outside Git.
